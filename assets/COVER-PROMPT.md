# AXguard cover photo — generation prompt

Use this with Midjourney, Flux, Ideogram, ChatGPT image, Gemini, etc.

**Target size:** GitHub-friendly **16:9** (ideal social/OG: **1280×640**; README hero also fine at **1600×900** or **1920×1080**).

---

## Prompt (copy/paste)

```text
Premium GitHub repository cover photo for AXguard by AwareXone, 16:9 landscape.

Brand: AwareXone open-source security tool. Product name: AXguard.
Tagline: Pre-ship security gate.

Composition:
- Centered large modern wordmark "AXguard" in clean bold geometric sans-serif, crisp white with subtle teal edge light
- Small uppercase label above the title: "AWAREXONE"
- Subtitle below in muted cool-gray monospace: "Pre-ship security gate"
- Optional tiny secondary line: "audit · triage · fix · report · ci"

Visual style:
- Deep charcoal / near-black background (#0a0e14 → #121820)
- Soft teal/cyan accent glow (#3dd6c6) as a single elegant light source from the left
- Abstract minimal protective gate/shield motif made of thin architectural lines and a faint circuit trace — not cartoon, not clipart
- High-end DevSecOps brand aesthetic: calm, sharp, expensive, editorial
- Generous negative space, ultra clean, Instagram-meets-GitHub

Hard constraints:
- No purple gradients
- No neon haze overload / no glow spam
- No people, faces, or hands
- No other company logos
- No fake UI dashboards, terminal walls of text, or stock “hacker in hoodie” imagery
- No watermarks, no extra random words

Mood: open-source security infrastructure for the AI era — builders gate what they ship before publish.
```

## What the tool is (context for the model)

AXguard is AwareXone’s open-source pre-ship security gate. Developers and AI coding agents run it before publishing code. It audits for secrets, auth/IDOR gaps, injection, SSRF, XSS, cloud misconfig, and AI-agent risks, then outputs HTML/Markdown/JSON reports. Companion to Agentic Bug Hunter (live hunting) — AXguard is the ship gate for builders.
